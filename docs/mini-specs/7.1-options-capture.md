## What

The Unusual Whales options tape captured raw, every session, with no
off-switch — the options twin of mini-spec 1.2. Capture must not wait for
decode maturity: this story ships a feeder that appends every raw frame
before any parsing, plus light frame *classification* for stats (ack /
data / unknown counts); full decode is 7.2.

- `internal/uwfeed/live.go` — `RunLive(opt LiveOptions) (LiveStats, error)`.
  Dial `wss://api.unusualwhales.com/socket?token=<key>`; join
  `option_trades:<SYM>` per universe symbol (189 individual joins — 7.0:
  all ack ok on one connection, no cap); capture-before-parse via
  `capture.Writer` (reused unchanged, own dir); reconnect with the equity
  feeder's capped-backoff ladder (1s→30s, reset after a >1min healthy
  connection), re-joining all channels on each new connection; 30s read
  deadline (same posture as equity: true silence cycles the connection
  harmlessly); control records connect/disconnect/reconnect/fatal/
  start/stop. An optional `Frame` hook is the 7.2 seam — the decoder plugs
  in without touching the read loop.
- `cmd/live-options/main.go` — mirror of `cmd/live` minus pipeline/view/
  buckets: writer opened first (loud ErrExists/ErrLocked refusal),
  `universe.Load` (same 189 symbols), signal handling (first Ctrl-C closes
  stop channel, second kills), 30s status line, manifest on close.
  Flags: `-baskets`, `-out data/capture-options`, `-until 17:30:00` ET
  (options print to ~17:00 per 7.0), `-url`, `-resume`.
  Key: `UNUSUAL_WHALES_API_KEY` (env, else `.env`).

## Decisions

- **C1 — Token never touches the record.** The API key rides in the URL
  query string (unlike Massive's in-band auth message), so `connect`
  control records and every log line carry a redacted URL
  (`…?token=REDACTED`). A test greps the capture stream for the key.
  *(Refined post-review 2026-08-19: redaction goes through net/url so
  duplicate `token=` parameters all collapse and fragments survive; the
  dial URL builder does too, keeping the query ahead of any fragment.)*
- **C2 — Fatal vs reconnect.** Handshake rejection with HTTP **401/403**
  is fatal (rejected credentials; retrying thrashes — review #1/#2 logic);
  other 4xx (a 429 in a reconnect storm) reconnects with backoff — ending
  the day's capture over a transient rate-limit would be self-inflicted.
  A non-ok join ack is logged and counted, not fatal — one bad symbol must
  not kill 188 good ones — **but a connection where every join is rejected
  and none succeeded is fatal**: that is mid-day entitlement/token
  revocation, and reconnecting would capture acks-only garbage all day
  with no error signal. *(Both refinements post-review 2026-08-19.)*
- **C2a — Tripwires can't be blinded (post-review 2026-08-19).** A frame
  whose payload is not a JSON object counts UnknownShape, never Data; a
  well-formed frame on a channel we never joined counts UnknownChannel
  (the universe-drift analog of feed's unknown-symbol counter). The cmd
  tripwire fires on either. Join messages are json.Marshal'd, never
  Sprintf'd — trader-edited symbols cannot produce malformed protocol
  JSON.
- **C3 — Separate capture dir, separate flock.** `data/capture-options/
  <date>/stream.jsonl` via `capture.NewWriter` unchanged. Never shares the
  equity dir; the equity session's blast radius is zero.
- **C4 — Classification-only stats in 7.1.** Frames are counted as
  ack-ok / ack-non-ok / data / unknown-shape by tuple sniffing; no field
  decode, no pipeline. Unknown-shape is the tripwire counter (equity's
  unknown-condition posture).
- **C5 — No bucket write in 7.1.** The capture is the record; buckets
  arrive in 7.4 via replay regeneration. Exit codes: 0 ok, 1 fatal.
- **C6 — 7.0 leftovers close here.** The first live session's capture
  answers recv−`executed_at` skew (one-liner over the stream) and wire
  payload confirmation; findings appended to data.md.

   next session onward.
