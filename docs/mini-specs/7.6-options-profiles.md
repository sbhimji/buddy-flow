# Mini-spec 7.6 — Options profiles & σ floors

Status: **resolved 2026-08-24** — unit suite green; real build over 20 days

Story: DEV-PLAN Phase 7 → 7.6. Gated by 7.5 (resolved).

## What

`internal/optprofile` + `cmd/profiles-options`: the 20-day time-of-day
matched baselines for the two signed per-minute series the buckets carry —
`net_conviction` (SECTOR §3.1's number) and `net_notional` (the unweighted
ask−bid, calls−puts premium derived from the six slices):

- Per-ticker: `data/profiles-options/<SYM>.csv`, 390 rows (09:30..15:59),
  `days, median_netconv, sigma_netconv, median_netnotional,
  sigma_netnotional`, median/MAD×1.4826 over the lookback days' minute
  values. A silent minute is a true zero (F13 analog).
- Per-basket: `data/profiles-options/baskets/<basket>.csv`, same columns,
  built as **day-level series** — for each day and minute, Σ member values
  first, then median/MAD across days (the 3.1 D2 precedent: signed sparse
  per-member medians sit at ~0 and MAD does not compose across members).
  Header stamps `members=` (D2a refusal on membership change).
- Floors: `_floors.csv` with `sigma_floor_netconv`, `sigma_floor_netnotional`
  (per-ticker families) and `sigma_floor_basket_netconv`,
  `sigma_floor_basket_netnotional` (basket families), each = frac × the
  median σ across the universe/baskets at that minute (D18: frac 0.25).
- Every file carries `weights=<version>@<hash>`; readers refuse a stamp
  mismatch (bucket inputs are read with the same refusal).

## Decisions

- **P1 — Coverage = file exists at the canonical path.** A day enters the
  lookback iff `<date>.csv` (not `.partial.csv`) exists; every symbol in a
  covered day contributes, zero if silent — a member with no option prints
  is normal (unlike equity D2b). `MinProfiledDays = 10` counts covered
  days; `-days N -through D` takes the N most recent covered days ≤ D.
- **P2 — Regular session only** in profiles (09:30–16:00 ET, 390 minutes).
  Post-16:00 prints stay in buckets; no baseline covers them (no display
  reads them either, v1).
- **P3 — Robust estimator** median / MAD×1.4826 (D6), MAD=0 → σ 0 → floor
  applies at read time via zguard (σ_used = max(σ, floor)); a floor of 0
  (nothing measurable at that minute) yields zguard's defined null.
- **P4 — Determinism**: two builds over the same inputs → byte-identical
  files; sorted symbols, shortest-round-trip floats, .tmp+rename.
