## What

The options twin of the 1.1/1.3 pair: a typed pipeline and the shared
decoder that live and replay both drive — the determinism contract.

- `internal/optingest` — `OptionTrade` (the fields 3.1's classifier and
  buckets consume; capture retains everything else), `Pipeline` (bounded
  queue, blocking `Submit`, single consumer `Run`, `Observer{
  ObserveOptionTrade(*OptionTrade)}`, `SetObserver` before Run), sliding-
  window uuid dedupe, counters (`Processed`, `MaxQueueDepth`, `Dupes`).
- `internal/uwfeed/decode.go` — `DecodeFrame(frame, p, stats)`: tuple
  parse, payload → `OptionTrade`, ms→ns, decimal-string parsing, submit.
  Used verbatim by the live `Frame` hook and by replay.
- `internal/uwfeed/capture.go` — `StreamCapture(path, p, ReplayOptions{
  Speed, PaceFrom, Log})`: replays a capture through `DecodeFrame` with
  the equity replayer's absolute-schedule pacing; control records skipped.
- `cmd/replay-options` — skeleton: `-capture`, `-speed`, `-pace-from`;
  decodes, drains, prints counter summary. Buckets/view arrive 7.4/7.7.

## Decisions

- **R1 — Decoder transcribes; classifier owns policy.** The decoder maps
  wire fields to struct fields mechanically (side *tag string* extracted
  from `tags[]`, `trade_code` passed raw). Sign conventions, sweep codes,
  weights — all 7.3, none here.
- **R2 — Struct carries only what downstream consumes**: id, underlying,
  OSI symbol, ExecNs, expiry (string, classifier parses+caches), type,
  strike, size, price, premium, open_interest, underlying_price (+ok flag
  — empty string on index names, D17), nbbo bid/ask, trade_code, side tag.
  Greeks/cumulative-side-volumes stay in capture, decoded never (re-decode
  from capture if a future story needs them).
- **R3 — Dedupe is a deterministic sliding window**, not session-lifetime:
  a ring of the last 2^20 print ids + map (~80MB worst case, vs several
  hundred MB session-lifetime — the 7.0 sizing note). Reconnect re-delivery
  lands within the window; live and replay see identical frame sequences,
  so the policy replays identically. Dupes counted, never observed twice.
- **R4 — Decode failures count, never crash** (`DecodeErrs`): the frame is
  already in capture; a torn or drifted payload must not kill a session.
  Distinct counters: parse failure vs non-universe channel (should be 0 —
  the feeder's UnknownChannel already trips).
- **R5 — Numbers**: decimal strings via `strconv.ParseFloat`; a field that
  fails to parse fails the whole print into DecodeErrs (no partial
  structs, no silent zeros — a zero premium is a measurement).
- **R6 — Replay pacing** copied from `internal/feed/capture.go` (absolute
  schedule, 30s max-sleep gap clamp, `PaceFrom` fast-forward). Speed 0 =
  instant.
