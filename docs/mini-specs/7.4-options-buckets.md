## What

`internal/optbucket` — per-underlying × 1-second aggregation of classified
prints (the 1.4 analog), one resolution all session, coarser views
derived. `Store` implements `optingest.Observer`, owns a 7.3 `Classifier`,
and persists to `data/buckets-options/<date>.csv`.

Per-bucket fields: `Prints, Contracts, PremCallAsk/Bid/Mid,
PremPutAsk/Bid/Mid, PremSweep, NetConviction, PrintsNoUprice,
PrintsZeroOI`. Mid folds mid_side + no_side + absent (all zero-sign).
Unweighted signed notional is derivable from the six premium slices at
read time and is not stored; `NetConviction` (Σ weighted) must be stored —
it depends on per-print context no aggregate preserves, which is exactly
why a weights change forces regeneration from capture.

## Decisions

- **B1 — Event-time bucketing** on `ExecNs/1e9` (the equity `sipNs`
  convention): live, instant replay, and paced replay produce identical
  stores; late prints amend their true second.
- **B2 — Session date discovered from the data**: the classifier (which
  needs the date for DTE) initializes lazily from the first observed
  print's ET date. A classifier init failure is sticky and fails
  `WriteCSV` loudly — never a half-classified file.
- **B3 — Store everything, name coverage honestly.** All seconds bucket
  (options print to ~17:00; the 1-second-all-day invariant). Coverage
  naming reuses `bucket.SpansRegularSession` + the `.partial.csv` rule;
  baseline discovery sees only spanning files.
- **B4 — CSV conventions inherited from 1.4**: self-describing header,
  `.tmp`+rename, shortest-round-trip floats, rows sorted (second,
  symbol), byte-identical across rebuilds. Header comment carries
  `weights=<version>@<hash>` plus the unclassifiable count;
  `ReadCSV(path, wantStamp)` refuses a stamp mismatch (D2a analog) and
  maps columns by name (column-compatibility contract: unknown columns
  ignored, absent optional columns are "not recorded", never zero).
- **B5 — Unclassifiable prints** (bad expiry, K3) are counted store-wide
  and stamped into the header — visible, never silently dropped from a
  file that claims to be a measurement.

## Done when (on replayed recorded data)

1. Unit: synthetic prints at `session.BucketStart` anchors — hand-computed
   bucket rows (each premium slice, sweep, NetConviction composition,
   flag counters), minute = Σ 60 seconds, write→read round-trip, stamp
   refusal, determinism (two writes byte-identical).
2. Full replay of a production session (08-24) into a bucket CSV twice —
   byte-identical; row spot-checks against an independent Python
   recomputation from raw stream.jsonl for 2–3 underlyings × seconds.
3. Classification-rate summary printed by the replay (sweep %, side
   split, no-uprice %, zero-OI %) — 7.3's done-when 3 closes here.
