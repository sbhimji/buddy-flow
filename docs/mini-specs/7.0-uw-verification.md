## What

Throwaway probes in `discovery-scripts/verify-uw/` (own go.mod, godotenv,
plain stdout report — the `verify-feed` posture) that turn the openapi.yaml
reading into observed fact. Two probes:

**`ws-probe`** — the live socket
(`wss://api.unusualwhales.com/socket?token=…`):
- Connect + join `option_trades:<SYM>` for 5 tickers, then the full 191
  (join-cap check; record every ack).
- Hold the joined connection idle > 90s with zero writes (heartbeat check:
  Phoenix servers conventionally drop silent clients; the spec is silent).
- Dump N minutes of raw frames to a scratch file for field study
  (market-hours run only).
- Measure message rate for our universe (Submit-queue and dedupe-map
  sizing; market-hours run only, ideally 09:30–10:30 ET).
- Record recv-vs-`executed_at` skew distribution (document, don't correct).

**`tape-probe`** — the historical tape
(`GET /api/option-trades/full-tape/{date}`):
- Download ONE past day's zip to scratch; record size, duration, any
  rate-limit headers or 429/502 behavior.
- Open it: document the inner format (file layout, encoding, header).
- Diff its per-row fields against the WS payload field list — **especially
  whether side `tags` (ask_side/bid_side/mid_side/no_side) are present**.
  This is the parity keystone: absent tags means historical baselines
  cannot be signed by the settled vendor-tags rule, and the plan's
  contingency (backfill-only NBBO-band derivation scored against WS tags,
  or live-accrued baselines) must be chosen here.
- Scan the day for universe symbols where `premium ≠ size × price × 100`
  (NANOS/XSP-class multipliers) — confirms the take-premium-verbatim rule
  and names affected tickers.

Deliverables beyond the probes: the Unusual Whales section drafted into
`docs/foundations/data.md` (endpoints, auth, frame format, heartbeat
finding, full-tape inner format, field-parity table) and the Phase 7
skeleton added to `docs/DEV-PLAN.md`.

## Decisions

- **V1 — Scratch-only output.** Every probe writes exclusively under a
  scratch dir (flag `-out`, no default inside `data/`) — the 2026-08-17
  incident rule: live smoke never touches the real session capture dirs.
- **V2 — Keys.** `UNUSUAL_WHALES_API_KEY` from env else `../../.env`
  (the `verify-feed` contract). The key never appears in output or in the
  frame dump filename.
- **V3 — Raw first.** The WS probe stores frames verbatim (pre-parse), so
  the field study reads what the wire actually carries, including fields
  the spec doesn't document (the equity `ds`-field lesson).
- **V4 — Off-hours split.** Connectivity, join-cap, and heartbeat findings
  are valid off-hours; message-rate and frame-dump findings require a
  market-hours run and are recorded separately. The story stays open until
  both halves are recorded.
