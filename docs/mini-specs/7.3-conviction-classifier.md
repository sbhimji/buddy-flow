Status: **resolved 2026-08-24** — unit suite green incl. the SECTOR deep-ITM fixture; classification rates on the 08-24 session: ask 44.2% / bid 46.7% / zero-sign 9.1% / sweep 28.3%, unclassifiable 0, stable across runs; an independent Python reimplementation from the spec matched the Go classifier on 69,677 bucket rows (QQQ/NVDA/AAPL, every column, 0 mismatches). ## What

`internal/optclassify` — the single source of per-print policy (the 0.3
print-inclusion analog): sweep detection, side sign, moneyness/DTE/size
weighting, and the two per-print numbers everything downstream sums:

    signed_notional   = premium × (call ? +1 : −1) × (ask_side ? +1 : bid_side ? −1 : 0)
    conviction_weight = w_sweep × w_money × w_dte × w_size
    weighted          = signed_notional × conviction_weight

Plus `LoadWeights(path) (Weights, hash, error)` for the PM-editable config
`docs/foundations/options-weights-v1.json`, hash = SHA-256 of the raw file
bytes, first 12 hex — the stamp every derived artifact carries (7.4+).

## Decisions

- **K1 — Moneyness measure (D14 made precise).** f = K/S − 1 for calls,
  1 − K/S for puts; f > 0 is OTM by fraction f, f < 0 is ITM by |f|.
  Bands, ATM first: |f| ≤ 5% → 0.5 (ATM wins inside the OTM band);
  OTM 5–15% → 1.0; OTM >15% → 0.5; ITM 5–15% → 0.5; deep ITM >15% → 0.1.
  Missing underlying price (D17: index names, `UPriceOK=false`) or a
  non-positive S or K → weight 1.0, `NoUPrice` flag counted.
- **K2 — Sweep set.** `trade_code` is a comma-joined OPRA condition list
  (e.g. `slan,isoi`); a print is a sweep iff any part ∈ {slan, slai,
  slcn, slci, slft}. Policy lives here only — the decoder passes the raw
  string through.
- **K3 — DTE** = calendar days, expiry date − session date, both ET
  dates; ≤ 45 → 1.25, else 1.0. 0DTE counts as ≤45. Negative (late print
  after expiry — shouldn't occur) clamps to 0. Parsed expiries cached per
  classifier instance; unparseable expiry → whole print unclassifiable
  (`ok=false`, counted by the caller — never a silent default).
- **K4 — Size/OI (D16).** size > frac × OI (strict) → 1.5; OI ≤ 0 → 1.0
  with `ZeroOI` flag counted. OI is prior-close by data contract.
- **K5 — Side sign** from the vendor tag verbatim (settled 2026-08-18):
  ask_side +1, bid_side −1, mid_side/no_side/absent 0. Zero-sign prints
  still classify (weights computed) so gross/denominator uses stay
  possible (D15); their weighted contribution is 0 by construction.
- **K6 — Config validation on load**: version string present, every
  weight > 0, 0 < atm_band_pct < otm_near_max_pct ≤ deep_itm_min_pct
  band sanity, frac > 0. A malformed config refuses loudly at startup —
  never a default silently substituted.

## Done when (on replayed recorded data)

1. Unit: table-driven band boundaries (each edge exactly at 5%/15%, both
   sides, calls and puts), sweep codes incl. comma-joined, all four side
   tags, D16/D17 defaults, premium-verbatim assertion (no ×100 anywhere),
   weights-hash changes when any config byte changes, K6 refusals.
2. The SECTOR fixture: a synthetic deep-ITM-heavy day produces near-zero
   conviction despite huge premium.
3. Classification-rate summary over one replayed production session
   (sweep %, side split, no-uprice %, zero-OI %), stable across two runs.
